# 粤语学习版本记录

## v1.0.0 — 2026-10-08

以用户确认的当前代码作为第一版管理基线，保留已有 Git 历史。
四个仓库（yue-frontend、yue-backend、yue-admin、yue-miniprogram）统一使用 v1.0.0 标签定位当前版本。
这是代码快照；数据库、服务器配置、本地密钥、音视频素材及线上部署状态不包含在此标签中。

本次纳入此前未提交的网页端电影模仿、场景对话、云端语音相关改动与测试，以及后端语音转写接口、服务和测试。后台和小程序沿用当前代码。

- 后端：Maven 离线测试通过，43 项测试，0 失败。
- 后台管理：生产构建通过；当前没有自动化测试文件。
- 微信小程序：18 项通话测试通过；TypeScript 类型检查通过；本次未执行微信打包和真机验证。
- 本次未验证线上运行及云端语音识别实际调用。

后续管理规则：
- 每个完成并验证的小修复或功能保存独立提交，提交说明写明具体变化。
- 正式发布时，小修复使用 1.0.1、1.0.2；新增功能使用 1.1.0；不兼容的大改使用 2.0.0。
- 发布标签写明受影响仓库；跨项目版本记录注明各仓库对应提交。
- GitHub 同步与上线部署分别记录；提交或推送成功不代表已上线。
- 密钥、本地配置、依赖和构建产物不纳入提交。项目根目录 version.json 是音频缓存版本，不能当作软件版本号修改。
