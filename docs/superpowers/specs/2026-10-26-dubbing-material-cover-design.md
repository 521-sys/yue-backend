# 电影配音素材卡片封面设计

## 意图

小程序“电影模仿”的素材列表卡片目前只有文字。每条电影配音素材需要一张横向封面，帮助用户在进入 Part 前快速识别内容。

## 目标与非目标

- 每条 `DubbingMaterial` 管理一张素材级封面，不是每个 Part 一张。
- 运营后台可上传、预览和替换封面。
- 公开素材 API 返回可缓存的 `coverUrl`；小程序卡片用图片显示，不在列表内嵌视频。
- 现有两条已发布素材从各自 Part 01 的 0.5 秒画面生成 16:9 初始封面，后续可在后台替换。
- 不做视频列表自动播放、不做每 Part 封面、不做在线裁剪编辑器，不改动 Part 预览页。

## 方案比较

1. **后端持久化封面 + 后台上传（已选）**：卡片只加载图片，性能稳定，运营可替换；代价是要改数据库、后端、管理端和小程序。
2. **后端每次自动截取视频首帧**：不需人工上传，但需要 FFmpeg 生成、缓存和失败恢复，且无法选择更合适的画面。
3. **小程序卡片内嵌静音视频**：只改小程序，但会同时加载多个 MP4，增加流量、解码开销和黑屏风险。

## 数据与存储

- `dubbing_materials` 新增可空的封面文件元数据：`cover_key`、`cover_original_name`、`cover_file_name`、`cover_content_type`、`cover_size_bytes`、`cover_width`、`cover_height`、`cover_version`。
- 文件保存到受控目录 `ADMIN_DUBBING_COVER_DIR`，生产建议 `/opt/yue/dubbing-covers`；数据库和该目录属于同一备份/恢复单元。
- 仅接受 JPEG/PNG，最大 5 MiB；服务端从文件内容解码格式和尺寸，不信任扩展名或客户端 MIME。最大边长 4096 像素，像素总数不超过 1600 万。
- 上传先写同目录临时文件，验证后原子移动；数据库失败时清理新文件，事务提交后才删旧文件。
- 发布前必须已有封面。迁移字段先保持可空，按“迁移 → 导入现有封面 → 验证 → 部署新后端”的顺序避免现有已发布素材中断。

## API

- 管理端新增 `POST/PUT /api/admin/dubbing-materials/{id}/cover?materialVersion=...`，上传或替换封面；已发布素材需先下架。
- 管理端新增 `GET /api/admin/dubbing-materials/{id}/cover?v=...`，继续使用管理员身份读取预览。
- 公开端新增 `GET /api/public/dubbing-materials/{code}/cover?v=...`，只允许读取已发布素材的封面，返回正确 `Content-Type`、`ETag` 和缓存头。
- 管理详情增加 `cover` 元数据；公开 `PublicMaterial` 增加 `coverUrl`。列表摘要可返回是否已有封面，不携带二进制数据。
- 封面替换更新素材版本与 `cover_version`，避免并发覆盖和旧缓存。

## 管理端

- “素材资料”区增加封面卡片：16:9 预览、文件名/尺寸/像素尺寸、JPEG/PNG 选择器、上传/替换按钮。
- 新建素材需先保存内容才能上传封面；有未保存表单改动时禁用封面上传，防止版本冲突。
- 已发布素材的封面选择器和替换按钮禁用，页面提示先下架。

## 小程序卡片

- `DubbingMaterial` 增加可选 `coverSrc`；API 适配层将相对 `coverUrl` 解析为完整 API 地址。字段可选是为了兼容后端升级窗口和旧测试数据。
- `MaterialCatalog` 在每张卡片顶部显示 16:9 `Image`，`mode="aspectFill"`；下方保留标题、难度、标签、Part 数和许可信息。
- 封面缺失或加载失败时显示固定比例的品牌渐变占位，不让整个素材目录加载失败。
- 图片与卡片其他区域一样可点击进入 Part 预览，不新增独立按钮。

## 现有素材初始封面

- 对 `pendatang-arrival` 和 `sfdph-wash-hands-cantonese` 各取 Part 01 在 0.5 秒的画面，缩放并补边为 1280×720 JPEG。
- 初始封面生成/导入脚本必须可重复执行，验证源视频和生成图片的 SHA-256，拒绝覆盖不同内容的目标文件。
- 运营人员后续可上传更好的自定义封面，不影响视频文件和台词。

## 验证与上线边界

- 后端：迁移幂等、图片真实格式/大小/像素限制、事务回滚清理、版本冲突、发布门禁、公开/管理读取权限与缓存。
- 管理端：新建/未保存/已发布状态禁用规则，上传表单和预览恢复。
- 小程序：`coverUrl` 解析、真实卡片渲染、缺失/加载失败占位、点击卡片导航。
- 上线必须独立备份数据库与封面目录，按顺序执行迁移、导入并验收现有两张封面，再切换后端、管理端和小程序版本。
- 本轮开发不自动执行生产迁移、部署、小程序上传或审核；这些需要后续明确的发布确认。
