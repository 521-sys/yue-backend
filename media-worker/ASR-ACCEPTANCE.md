# 本机自动生成台词验收记录

日期：2026-10-11。对应前端计划 `docs/superpowers/plans/2026-10-10-local-video-transcription.md`。

## 已验证

- 完整媒体测试：13 项通过，包括已有 FFmpeg 渲染测试。
- 完整前端测试：104 项通过；Vite 生产构建通过。
- `git diff --check`：前后端均通过。
- 实际服务监听 `127.0.0.1:8765`，health 返回 ready。
- 本地 222.962 秒、约 40.7 MiB 有声视频：HTTP 请求用时 29.58 秒，生成 30 句；所有时间满足 `0 <= startMs < endMs <= 视频时长`。
- 浏览器导入同一视频，点击识别后显示 30 句；第 2 句定位到 46.2 秒，改字后导出的 SRT 包含修改内容。
- 12 秒可控静音 WebM：真实模型 HTTP 返回 `200 {"cues":[]}`。
- 自动化测试覆盖失败/零句保留录音和台词、取消替换、切换视频和卸载后的迟到结果、SRT 读取与识别的互斥。

## 审查修复

- faster-whisper 在 tokenizer 文件缺失时可能联网回退。现同时检查 `model.bin`、`config.json`、`tokenizer.json`，模型缺失或加载失败返回 503。回归测试先失败，修复后通过。
- SRT 异步读取期间禁止启动识别；读取结束后校验当前视频请求序号。竞态回归测试先失败，修复后通过。

## 尚未完成的验收及限制

- 浏览器逐句录音已触发，但未完成保存结果核验；后续代码热更新重置了页面状态。
- 浏览器导入静音视频的操作被自动审批系统因额度用尽而拦截。未完成页面零句提示与断开服务后重试的人工验收；这些路径已有自动化测试，不能替代完整浏览器验收。
- TypeScript 检查仍报既有 `LearningState.seen` 与测试 setup 中未使用的 `@ts-expect-error` 错误；本轮不修改这些无关文件。
- 识别结果是初稿，存在错字和句尾时间偏长；未量化字幕准确率或逐句时间误差。
- 轻微待改进：FFprobe 成功后才发生的音频解码错误目前返回通用 500；理想情况下应分类为 422。页面仍保留旧内容并提示失败。
- 不包含背景音分离、工程持久化、网页成片导出或公网部署。
